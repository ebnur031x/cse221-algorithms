NOW, how to detect a cycle during DFS

dfs(A)  [PAUSED — still on stack]
  dfs(B)  [PAUSED — still on stack]
    dfs(C) → sees edge C → A
A depends on B, B depends on C, C depends on A. Circular. No valid order.


so, Key distinction (this is the trick):

Edge to a node still on the call stack (paused) → cycle! ❌
Edge to a node already finished (popped off) → fine, no cycle ✅
ArrayList + reverse() — you manually call Collections.reverse(). Push order [E,C,D,A,B] → explicitly reversed → [B,A,D,C,E].


and another way, is, a bit less cluttered way. Real Stack + pop() — you never reverse anything. The Stack data structure is LIFO (last-in-first-out) by nature — reading top-to-bottom is popping, automatically, no extra function call. Not an action, it's just what a Stack is.

SCC- Strongly Connected Components.

a group of nodes where everyone can reach everyone (A→B and B→A, through some path). (not necessarily directly)

Like, i learnt in cycle detection, SCC is basically "cycle detection, but grouping.

A → B
B → C
C → A

All 3 can reach each other → one SCC = {A, B, C}
